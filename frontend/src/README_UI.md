# UI design system — NEXUS

Visual language: near-black backgrounds, violet primary accents, turquoise conversion highlights, rounded cards, fine borders and a dense enterprise analytics layout.

Pages:
- Overview: KPI cards, session trends, revenue and source table.
- Acquisition: source ranking and session comparison.
- Intelligence: automatic descriptive insights, doughnut chart, recommendations and sortable matrix.
- Conversion funnel: four-stage visual explorer with volume/share toggle.
- Data sources: browser-local CSV import with validation.
- Tracking & privacy: GA4 tracking taxonomy and Consent Mode v2.

**Data integrity:** Demo figures are synthetic and explicitly labeled. Actual figures require running SQL against BigQuery and importing the results. Insights are descriptive, not causal, and use the same attribution caveats as the SQL files.
