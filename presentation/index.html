03 / DÉMONSTRATION

Une requête.
Un résultat vérifiable.

SELECT
COUNT(*) AS sessions_proxy
FROM
`bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
WHERE
event_name = 'session_start'
AND _TABLE_SUFFIX BETWEEN
'20201101' AND '20210131';

Extrait SQL illustratif cohérent avec le périmètre étudié. Démo live : ouvrir les requêtes du dépôt et le prototype.

05 / LECTURE CRITIQUE

Ce que les chiffres
ne disent pas.

01 / DONNÉES

Échantillon public

Historique 2020–2021 ; données anonymisées et partiellement obfusquées.

02 / MÉTRIQUES

Proxy ≠ réalité complète

session_start et user_pseudo_id ne sont pas des comptes exacts de visites et personnes.

03 / ATTRIBUTION

First-user ≠ session

Les sources décrivent l’acquisition initiale, pas le canal de chaque session.

3 RECOMMANDATIONS POUR UNE ENTREPRISE MAROCAINE
01

Renforcer le SEO

Suivre les pages d’entrée et les requêtes organiques.

02

Taguer les campagnes

Normaliser les UTM et vérifier les sources directes.

03

Comparer les périodes

Surveiller saisonnalité et conversions, pas seulement le trafic.
