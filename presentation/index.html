SELECT
  FORMAT_DATE('%Y-%m', PARSE_DATE('%Y%m%d', event_date)) AS mois,
  COUNT(*) AS session_start_events
FROM `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
WHERE event_name = 'session_start'
GROUP BY mois
ORDER BY mois;
01Filtrer les événements session_start.
02Agréger les événements par mois.
03Comparer les sources d'acquisition.

Une méthode reproductible : même périmètre, mêmes définitions, résultats vérifiables.
